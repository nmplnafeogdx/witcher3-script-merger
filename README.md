## Overview

The Witcher 3 Script Merger is an essential tool for players using multiple Witcher 3 mods that modify the same Lua script files. It automatically detects conflicts and merges the differing changes using a three-way merge algorithm, allowing otherwise incompatible mods to coexist. Without it, only the last-loaded mod's version of a conflicted script file is applied.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **The Witcher 3 Script Merger** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Conflict Detection** | Identifies all script files modified by more than one installed mod |
| **Three-Way Merge** | Merges conflicting mod changes using proven three-way diff algorithm |
| **Preview Merges** | Preview merge results before applying to catch manual conflict areas |
| **Batch Processing** | Merges all detected conflicts in one automated batch operation |
